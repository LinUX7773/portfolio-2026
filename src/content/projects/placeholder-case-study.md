This page is a reusable template. The layout stays the same for every case study. The writing, images and project facts live in this Markdown file.

## Context

Add a short description of the product, the organisation and the people you designed for. Keep it specific. Do not add metrics until you have real numbers.

## Problem

What was difficult, unclear or costly for users or the business? Write the problem in plain language.

## Research

Describe how you learned about the work. Interviews, observation, workshops, analytics or expert reviews can all live here.
